01 — OVERVIEW

An experimental new publishing platform.

The Stacks is a space dedicated to advancing knowledge through collaborative research and open-access publishing. The brand should feel the way the platform reads: careful, institutional, and quietly confident, never loud.

PRINCIPLE 01
Trust stillness
Whitespace, flat surfaces, and restraint do the work. Working UI stays flat. The expressive mesh is saved for big moments like the hero.
PRINCIPLE 02
Structure as texture
Mono type signals structured data everywhere: metadata, labels, even buttons. It is the platform's fingerprint.
PRINCIPLE 03
Borders, not shadows
Hairlines and 1px rings separate the interface. Shadows are reserved for modals; color does the rest.
02 — LOGO

The mark

The logo pairs the wordmark with a 4×4 grid crossed by a single 30° diagonal — a quiet nod to organized knowledge in motion. Use the full lockup wherever space allows; fall back to the mark for avatars and tight chrome.

05 — ICONOGRAPHY

Icon set

The icon library is Material Symbols (Rounded, weight 400). Its FILL axis carries the two styles: fill 0 for outline, fill 1 for filled. Icons display at 18–24px and inherit text color through currentColor — #262626 on light surfaces, #FFFFFF on dark. Keep the weight at 400; never alter it.

When a new icon is needed, pull it from Material Symbols Rounded (400) only. One source keeps the set visually consistent and easy for anyone extending The Stacks to maintain.

06 — EXPRESSIVE SURFACES
FUTURE-FACING

Expressive surfaces

Future-facing guidance, not current production usage. The current site is a minimal reskin of existing layouts, so color and surface treatments haven’t been pushed far yet. This section preserves some of the original brand direction and shows where the system could go.

Use one sanctioned gradient treatment: a soft pastel mesh with fine film grain. Best for large expressive surfaces, such as covers, section dividers, and empty states. Avoid using it behind long-form body text or dense UI.

08 — VOICE & TONE

How we sound

Institutional but direct — as if a careful editor wrote it. Declarative sentences, plain scientific language, the platform's own voice. No hype, no exclamation points, no emoji.

CASING

The product name is always The Stacks. Everything else is sentence case — page titles, headings, buttons, labels. A publication is a pub.

DO
"An experimental new publishing platform."
"Enter your details to get started with The Stacks."
"Create a pub" · "Log in" · "Latest publications"
DON'T
"Revolutionary science, unleashed! 🚀"
"Welcome back 👋"
"Create A Pub" · "Login" · title-case everything

10 — ACCESSIBILITY

Readable by everyone

Accessibility isn't a compliance checkbox — it's how an open platform keeps its promise. If the work is meant for everyone, it has to be readable by everyone. The Stacks targets WCAG 2.1 AA across color, type, structure, and motion.

CONTRAST
4.5:1, always
Body text clears 4.5:1, large text 3:1. Muted greys are tuned to stay legible — never decorative. Accent colors carry fills and bars, not text on light.
STRUCTURE
Reads without sight
Headings in order, real labels on every control, alt text on every image, a declared page language. The document makes sense top to bottom in a screen reader.
INPUT
Keyboard & touch
Visible focus rings, full keyboard reach, and 44px minimum hit targets. Nothing depends on hover or color alone to be understood.
MOTION
Calm, and optional
Animation stays functional and honors prefers-reduced-motion — when a reader opts out, the interface holds still.
