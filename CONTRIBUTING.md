# Contributing to The Stacks

Thanks for your interest in The Stacks!
We run it the same way as Raven, so [Raven's contributing guide](https://github.com/Astera-org/raven/blob/main/CONTRIBUTING.md) covers how the project is run, what we welcome, and how to report a security issue.

## Make a change

Note: This section is for Astera team members.
We don't accept outside contributions yet.

See [`frontend/README.md`](./frontend/README.md) to set up the website, and the README in each folder for the other packages.
Before you open a pull request, run `pnpm run precommit` and `pnpm test` in `frontend/`.
If your change also needs a change in Raven, link the Raven pull request in your description.
